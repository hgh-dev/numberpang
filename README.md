# 넘버팡 (Number Pang)

6~7세 어린이가 두 숫자를 이어 더하기와 빼기를 연습하는 무료 로컬 웹앱입니다. HTML/CSS/JavaScript로 만들었으며 서버 계정, 데이터베이스, 외부 라이브러리, 외부 글꼴이 필요하지 않습니다.

## 내 컴퓨터에서 실행하기

1. 터미널을 엽니다.
2. 아래 두 줄을 차례대로 입력합니다.

```sh
cd numberpang
npm start
```

3. 브라우저에서 **http://127.0.0.1:4173** 을 엽니다.
4. 종료하려면 터미널에서 `Control + C`를 누릅니다.

Node.js/npm과 Python 3가 있는 환경용 명령입니다. npm이 없다면 `python3 -m http.server 4173 --bind 127.0.0.1`로 실행해도 됩니다. `index.html`을 더블클릭하는 방식은 모듈과 PWA 때문에 지원하지 않습니다.

## 게임 방법

- ‘내가 정할래’에서 더하기(목표 0~18)와 빼기(목표 -9~9)를 고릅니다. 부호와 목표 숫자 위의 작은 랜덤 버튼으로 각각 앱에 맡길 수도 있습니다. 부호만 랜덤이고 숫자를 직접 고를 때는 두 연산에 공통인 0~9를 고릅니다. ‘너가 정해줘’는 둘 다 랜덤으로 고릅니다.
- 시작 후 3, 2, 1 카운트다운이 끝나면 소요 시간을 잽니다. 시간 제한은 없습니다.
- 상하좌우로 붙은 숫자를 드래그하거나 하나씩 눌러 선택합니다. 대각선과 빈칸은 선택할 수 없습니다.
- 빼기는 **먼저 선택한 숫자 − 다음 선택한 숫자**입니다. 예: 목표 -5는 2 → 7.
- 정답마다 기본 100점이 추가됩니다. 5초 안에 이어 맞히면 50점씩 콤보 보너스가 증가하며 한 번에 최대 500점입니다.
- 틀려도 점수·시간 벌점이 없습니다. 콤보만 초기화됩니다. 힌트를 누르면 남아 있는 모든 정답 쌍의 블록이 세 번 반짝입니다.
- 제거된 자리는 위의 숫자가 내려옵니다. 정답이 없으면 남은 블록만 다시 섞습니다. 블록을 모두 없애면 게임이 끝납니다.
- 완료 후 저장에 동의하면 이름을 입력할 수 있습니다. 기록 보기에서 이름, 완료 시간, 달성 날짜와 시간을 빠른 시간 순으로 볼 수 있습니다.
- 게임 시작 버튼 아래의 기록 보기에서 순위를 확인할 수 있습니다. 숫자 0~9는 각각 고유한 색으로 표시됩니다.
- 다른 앱으로 이동하면 자동 일시정지됩니다. 돌아와서 ‘계속하기’를 누르세요.
- 기록은 같은 브라우저와 기기에만 저장됩니다. 브라우저 데이터를 지우면 기록도 지워집니다. 저장이 차단된 환경에서도 게임은 가능합니다.

## 인터넷 주소로 배포하기

저장소: https://github.com/hgh-dev/numberpang

main에 변경을 반영하면 GitHub Actions가 검사·테스트 후 dist/를 Pages에 배포합니다. 최초 한 번 Settings → Pages → Source를 GitHub Actions로 지정하세요. 다른 호스팅에는 npm run build로 생성한 dist/를 업로드하세요.

```text
index.html
style.css
app.js
engine.js
sw.js
manifest.webmanifest
icons/ (폴더 전체)
```

### GitHub Pages

1. GitHub에 새 저장소를 만들고 프로젝트 파일을 업로드합니다.
2. 저장소 Settings → Pages의 Source를 GitHub Actions로 선택합니다.
3. Actions에서 Test and deploy Number Pang을 실행하거나 main에 변경을 반영합니다.
4. 배포 완료 후 제공되는 HTTPS 주소를 휴대폰에서 엽니다.

경로가 `사용자.github.io/numberpang/`처럼 하위 경로여도 상대 경로로 정상 작동하도록 구성했습니다.

### Cloudflare Pages

정적 파일 직접 업로드 방식으로 위 파일들이 들어 있는 폴더를 업로드합니다. 빌드나 환경 변수는 필요하지 않습니다. Git 연동 시에는 빌드 명령 없이 정적 파일이 있는 루트 폴더를 출력 대상으로 지정합니다.

## 휴대폰 홈 화면에 설치

먼저 배포한 **HTTPS 주소**에 온라인으로 한 번 접속하세요.

- Android: Chrome 메뉴의 설치/홈 화면 추가를 이용합니다. 지원되는 브라우저에서는 게임 설정 화면에 설치 버튼도 나타납니다.
- iPhone/iPad: Safari의 공유 메뉴에서 ‘홈 화면에 추가’를 선택합니다.
- 최초 파일 캐싱이 끝난 뒤에는 인터넷 없이 기본 게임을 실행할 수 있습니다. 브라우저가 저장공간을 정리한 경우 온라인에서 다시 열어 주세요.
- 컴퓨터의 `127.0.0.1` 주소는 휴대폰에서 접속할 수 없습니다. 휴대폰 설치에는 배포 주소를 사용하세요.

## 업데이트

GitHub Actions 빌드는 파일 내용에서 캐시 버전을 자동 생성합니다. 앱은 실행하거나 다시 활성화할 때 새 버전을 확인하며, 켜진 상태에서도 10초마다 확인합니다. 새 버전이 준비되면 Yellow Note처럼 **새 버전이 준비되었습니다** 배너와 **저장 후 업데이트** 버튼을 보여 줍니다. 버튼을 누르면 진행 중인 게임을 저장한 뒤 새 버전을 적용합니다. 저장에 실패하면 업데이트를 보류합니다. 적용 후 게임은 일시정지된 상태로 이어서 할 수 있습니다. 인터넷이 끊긴 동안에는 기존에 저장된 버전으로 계속 실행됩니다.

## 파일 구조

- `engine.js`: UI에 의존하지 않는 계산, 판 생성, 중력, 시간, 점수와 콤보 로직
- `app.js`: 터치/마우스/키보드, 화면 전환, 효과음, 일시정지, 기록 저장
- `style.css`: 작은 화면·가로 모드 대응, 안전 영역, 타일 효과와 움직임 감소
- `sw.js`, `manifest.webmanifest`, `icons/`: 오프라인 실행과 설치
- `tests/engine.test.js`: 핵심 게임 규칙 자동 테스트

## 테스트

```sh
npm test
```

엔진 테스트가 더하기·0·음수·빼기 선택 순서·인접/빈칸 검사·중력 보존·모든 목표의 정답 보장·콤보 경계와 상한·시간 제한 없는 진행·블록 전체 제거 시 종료·남은 블록 재배치를 검증합니다.

현재 실행 환경에서는 실제 브라우저의 업데이트 동작을 확인하지 못했습니다.

실제 Android/iOS 기기의 터치, 홈 화면 설치, 폴드 접기/펼치기와 회전은 이 개발 환경에서 직접 검증하지 못했습니다. 배포 후 아래를 확인해 주세요.

- 작은 세로 화면과 가로 화면에서 숫자판 100칸이 잘리지 않는지
- 한 손가락 드래그와 두 번 탭이 모두 되는지
- 드래그 도중 두 번째 손가락을 대도 중복 정답이 생기지 않는지
- 정답 애니메이션 중 홈 화면으로 나갔다 돌아오면 점수/판이 유지되는지
- 설치 후 비행기 모드에서 종료/재실행해도 열리는지
- 업데이트 후 실행 중인 앱에 새 버전 배너가 표시되는지
- 게임 중 **저장 후 업데이트**를 누르면 일시정지 상태로 이어지는지
